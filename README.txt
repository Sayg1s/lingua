# Lingua

Приложение для изучения английского по карточкам. СДЕЛАНО НЕЙРОНКОЙ! Скрывать нечего.

Для импорта готовых наборов карточек заходите на специализированные сервисы, копируйте пачки карточек ctrl c + ctrl v, кидаете иишке и просите скомпилировать файл в формат json. Далее просто импортируете в приложение.

Весь функционал ПОЛНОСТЬЮ бесплатный, но внизу есть реквизиты для поддержки, если кто изъявит желанием.
