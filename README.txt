# Lingua 2.0

## Запуск на компьютере
Открой `index.html` в браузере. Все данные наборов хранятся локально в браузере (LocalStorage).

## Установка на телефон (PWA)
Для установки нужен сайт по HTTPS (или localhost для тестирования). Просто открыть HTML-файл с диска недостаточно: браузеры не разрешают Service Worker для `file://`.

1. Загрузи ВСЕ файлы из этой папки на статический хостинг с HTTPS (например, GitHub Pages или Netlify).
2. Открой адрес сайта в Chrome/Edge на Android или Safari на iPhone.
3. Android: меню браузера → «Установить приложение» / «Добавить на главный экран».
4. iPhone: кнопка «Поделиться» → «На экран Домой».

## Интервальное повторение
- «Не вспомнил» — повтор через 10 минут и фиксация ошибки.
- «Вспомнил» — следующий интервал: 3 дня, затем 7 дней, затем увеличение по коэффициенту лёгкости.
- Тест и письмо также обновляют расписание.
- «Повторить сегодня» показывает карточки, у которых наступил срок.

## Импорт карточек из Quizlet
1. На сайте Quizlet открой свой набор → меню `⋯` → `Экспорт`.
2. Выбери табуляцию между термином и определением и новую строку между карточками.
3. Скопируй экспорт и в Lingua открой нужный набор → `Массовый импорт`.
4. Вставь текст в поле или выбери сохранённый файл TXT/TSV/CSV. Нажми `Импортировать карточки`.

Импортёр автоматически распознаёт табуляцию Quizlet, CSV с разделителем `;`, а также прежний формат приложения:
`Apple - Яблоко | I eat an apple every day. | Я ем яблоко каждый день.`

При импорте из Quizlet добавляются термин и определение; примеры можно добавить и отредактировать позже. JSON-импорт наборов также поддерживается.
